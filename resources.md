# Ресурси / Resources

## SQL-тренажери та курси

- [sql-academy](https://sql-academy.org/ru/sandbox) — інтерактивний курс і пісочниця.
- [SQLZoo](https://www.sqlzoo.net/) — безкоштовні вправи.
- [SQLBolt](https://sqlbolt.com/) — короткий інтерактивний курс для початківців.
- [Наш SQL-тренажер на кредитних картках](https://antonemec.github.io/analyst-html-tools/sql-trainer.html) — віконні функції, roll rate, вінтажі.
- [Mode SQL Tutorial](https://mode.com/sql-tutorial/) та [LeetCode Database](https://leetcode.com/problemset/database/) — додаткові задачі.

## Дані та практика

- [BigQuery](https://console.cloud.google.com/bigquery) — публічні датасети та sandbox.
- [Kaggle](https://www.kaggle.com/) — датасети, ноутбуки, змагання.
- Відкриті дані НБУ, Держстат, data.gov.ua.

## Візуалізація

- [Tableau Public](https://public.tableau.com/) — безкоштовні інтерактивні візуалізації.
- [Looker Studio](https://lookerstudio.google.com/) (раніше Google Data Studio) — безкоштовні дашборди.
- Power BI Desktop — безкоштовний клієнт.

## Метрики й статистика

- [Довідник з кредитних карток](https://github.com/antonemec/Retail-Data-Analyst-of-credit-cards-portfolio).
