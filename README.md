## Як користуватися / How to use

1. Оцініть рівень: пройдіть тренажер без підготовки й подивіться на слабкі теми.
2. Складіть план за [30-денною програмою](study-plan-30-days.md).
3. Відповідайте вголос і засікайте час: у реальному інтерв'ю важлива структура відповіді, а не лише правильність.
4. Повторюйте слабкі питання через 1, 3 і 7 днів (інтервальне повторення).

## Рівні / Levels

- **Junior:** SQL-основи, базова статистика, уважність до даних.
- **Middle:** віконні функції, A/B-тести, метрики продукту, самостійний аналіз.
- **Senior:** постановка задач, оптимізація, вплив на рішення, наставництво.
